          서버

          AI 승인 방식

          • 외부로 데이터를 보내는 명령 (curl 업로드, git push, scp, ssh 등)
          • AI 계정 인증 정보에 접근하는 요청
          • 작업 폴더 전체를 지우는 명령
          • 샌드박스 밖 도구 (MCP 등, 모든 방식에서 물어요)
          • 아래 '항상 묻기 목록'에 있는 명령

          AI·라우팅

          의미 기반 작업 라우팅 (Clef)

          애매한 요청을 Cloudflare Workers AI의 Clef-flash로 분류해 조사·검증 단계를 붙입니다.

          Clef 라우팅 사용
          모델 자동 선택켜면 AI를 지정하지 않은 요청에 알맞은 AI를 자동으로 고릅니다. 직접 고른 AI가 항상 우선하고, 실패하면 기본 방식으로 처리해요.
          확신이 이 값보다 낮으면 기본 방식으로 처리해요 (0.30–0.95).
          요청 원문 저장 허용끄면 요청 원문 대신 해시만 기록해요.

          추가 로컬 모델 서버

          OpenAI 호환 서버를 더 추가하면 그 모델이 로컬 모델 목록에 나타나요. API 키는 저장 후 다시 볼 수 없어요.

            제목을 만들 때 쓸 로컬 모델이에요. 실패하면 세션의 기본 모델이 만들어요.
            검증에 사용할 모델고른 모델이 AI가 한 작업의 결과를 글로만 보고 검증해요. 아무것도 고르지 않으면 지금처럼 동작해요.
              최신 자료나 출처가 필요한 요청에서 먼저 조사를 맡아요. 실패하거나 고르지 않으면 조사 없이 기본 AI가 직접 답해요.
