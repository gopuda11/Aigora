# Aigora

[English](README.md) · [API 설정](docs/setup-api.md) · [로컬 모델](docs/local-models.md) · [보안](SECURITY.md) · [개인정보](PRIVACY.md)

Aⁱgora(아이 고라)는 직접 호스팅하는 협업 AI 작업 공간입니다. 사람과 AI가 방의 공유 피드와 파일을 함께 사용하고, 개인 작업은 소유자별 비공개 채널에서 진행합니다. Anthropic/OpenAI API 키와 OpenAI 호환 모델 서버를 함께 사용할 수 있습니다.

소유자: gopuda11

## Built with AI — AI와 함께 개발

**gopuda11**이 기획·구현·검토 역할을 나눈 AI 에이전트를 지휘하고, 통합과 릴리스의 최종 책임을 맡습니다. Clay와 Clagentic을 기반으로 협업 방, 비공개 채널, 라우팅과 미디어 기능을 확장했습니다. [AI 개발 과정](docs/BUILDING-WITH-AI.md)에 실제 회귀 수정 사례, 소유자 도구로 측정한 개발 수치와 검증 한계를 기록했습니다.

## 주요 기능

- 방 생성·초대·역할 관리·보관·복원, 공유 피드, 댓글·답글·반응·고정 메시지, 공유 게시물, 멤버 `@멘션`, 알림과 메시지 링크.
- 소유자별 비공개 채널과 세션, 폴더·그룹·이름 변경·삭제, 대화 기록과 다른 제공자의 비공개 세션.
- Claude/Codex API 에이전트, 스트리밍 답변, 도구 승인과 중지, 진행 표시, 문맥·토큰 표시, 파일 결과와 오류 진단.
- 메시지별 AI 선택과 별칭, Clef/JEV 및 앙상블 라우팅, 자동 선택(명시적 활성화), 판단 설명·보류·대체, 다단계 연구·작업·검증과 실행 기록.
- Ollama 등 호환 서버의 로컬 채팅, 모델 탐색, 추가 엔드포인트, 제목 생성과 교차 검증. 기본 로컬 어댑터는 텍스트 채팅이며 도구 실행 루프가 없습니다.
- 파일 업로드·선택·미리보기·다운로드, AI 결과 파일, 지원 문서의 텍스트 추출, 별도 ONLYOFFICE 서버를 통한 DOCX/XLSX/PPTX 공동 편집. HWP는 다운로드만 지원합니다.
- API 또는 별도 Whisper 호환 서버를 통한 음성 전사. 동영상·강의 오디오 추출, 타임스탬프 전사, 강조 구간·장면·프레임 선택과 후속 AI 이해. 로컬 LLM 강조 보정과 실험적 펜/레이저 감지는 별도 조건이 필요합니다.
- 프롬프트 코칭, 스킬 카탈로그·Git 소스, 프로젝트 지침, MCP/지원 플러그인, 예약 실행·반복 작업, 동시 실행 관리, 작업 트리·스냅샷.
- 콘솔의 터미널·파일 편집·Git/차이 보기·브라우저 도구·쪽지·직접 메시지. 협업 페이지와 콘솔에 표시되는 기능은 다릅니다.
- 한국어/영어, 밝게/어둡게/시스템 테마, 콘솔 색상 테마·표시 설정, 휴대폰 UI와 PWA, 초안·스크롤 복원, 재연결과 오프라인 전송 대기열. 오프라인에서 에이전트를 실행하지는 않습니다.
- 계정·PIN·프로필·로그아웃 관리, 벨/승인 알림, 선택적 웹 푸시·SMTP, 관리자 권한·서버·라우팅·전사 설정과 감사 로그.

전체 기능과 제약은 [영문 README](README.md)에 정리되어 있습니다.

## 빠른 시작

Node.js **22.15 이상**과 npm을 사용합니다. 포함된 에이전트 격리 구현은 Linux x64, `bwrap`, Python 3, 사용자/네트워크 네임스페이스와 정상적인 `systemd-run --user`가 필요합니다.

```sh
git clone <public-repository-url>
cd Aigora
npm ci
export ANTHROPIC_API_KEY='<your-api-key>'
export OPENAI_API_KEY='<your-api-key>'
node bin/cli.js --host 127.0.0.1 --no-https --no-update
```

별도 프런트엔드 빌드는 없습니다. 터미널 설정 안내를 따른 뒤 표시된 주소(기본 포트 2633)를 열고 설정 코드로 관리자 계정을 만드세요. `node bin/cli.js --add .`로 프로젝트를 추가합니다. 사용할 제공자의 키만 설정하면 됩니다. 로컬 전용 구성은 에이전트 API 키를 생략할 수 있습니다.

기본 바인딩은 `0.0.0.0`이므로 위처럼 명시하세요. 외부 접속에는 TLS가 필요합니다. 브라우저의 CDN/폰트 의존성 때문에 서버 설치만으로 완전한 오프라인 UI가 되지는 않습니다.

**방의 Claude/Codex 실행은 기본 격리, 비공개 채널은 기본 격리 해제**입니다. 비공개 채널 격리는 `privateExecution.claude/codex: true`로 켜야 합니다. API 키가 없으면 `credential_unavailable`로 거부하며 기존 계정 인증으로 대체하지 않습니다. 관리자도 서버에 저장된 내용을 볼 수 있고, 전사는 틀릴 수 있습니다. 사용자 초대 전에 보안·개인정보 문서를 확인하세요.
